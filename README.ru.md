# olx-mcp

[English version](README.md)

[MCP](https://modelcontextprotocol.io)-сервер, с которым ИИ-ассистент (Claude Code, Claude Desktop,
openclaw, zeroclaw и любой другой MCP-клиент) может **искать на [OLX.pl](https://www.olx.pl)**,
польской доске объявлений. **Аккаунт не нужен.**

Сервер ещё и **смотрит фото**. У каждого объявления проверяется описание. Если описания нет, оно слишком
короткое или шаблонное, объявление получает пометку, и модель может скачать фото как картинки и
описать, что на самом деле продаётся.

> **Неофициальный проект.** Он не связан с OLX и использует те же внутренние JSON-эндпоинты, что и сам
> сайт olx.pl. OLX может их изменить в любой момент. Используй для личного поиска в небольших объёмах
> и соблюдай правила OLX.

## Что можно попросить

- «Найди б/у PS5 в Кракове до 1500 zł, сначала новые».
- «Покажи мини-ПК на Ryzen 7 по всей Польше и скажи, какие продают дешевле рынка».
- «Открой это объявление и проверь по фото, есть ли на велосипеде повреждения».
- «В каких категориях есть объявления "dyson" и сколько их?»

## Возможности

- Поиск по тексту с категорией, городом и радиусом, ценой, сортировкой и фильтрами категории.
- Поиск id городов, районов и регионов. Список категорий с числом объявлений.
- Любая ссылка olx.pl превращается в параметры поиска.
- Полные данные объявления: описание, параметры, все фото, продавец, место на карте, доставка.
- Фото отдаются картинками: можно задать размер и листать. Скачиваются напрямую с CDN OLX.
- Проверка описания у каждого объявления (`info.needs_photo_review`).
- Бережно к сайту: одна сессия браузера, между запросами к OLX не меньше 1 секунды.

## Требования

- Python 3.12+ и [uv](https://docs.astral.sh/uv/)
- Chromium или Google Chrome. Берётся системный, если есть, иначе сборка Playwright.
- **Графический дисплей** (X11 или Wayland) или Xvfb на сервере без экрана. Подробнее в разделе [Как это работает](#как-это-работает).

## Установка

```bash
git clone https://github.com/dmytrochornyi/olx-mcp.git
cd olx-mcp
uv sync
# Только если нет системного Chromium/Chrome:
uv run playwright install chromium
```

Проверить запуск (сервер ждёт MCP-клиента на stdin, остановить можно Ctrl+C):

```bash
uv run olx-mcp
```

## Подключение к клиенту

### Claude Code

```bash
claude mcp add -s user olx -- uv run --directory /path/to/olx-mcp olx-mcp
```

Перезапусти Claude Code и проверь подключение командой `/mcp`.

### Claude Desktop и другие клиенты с JSON-конфигом

```json
{
  "mcpServers": {
    "olx": {
      "command": "uv",
      "args": ["run", "--directory", "/path/to/olx-mcp", "olx-mcp"],
      "env": {
        "WAYLAND_DISPLAY": "wayland-1",
        "XDG_RUNTIME_DIR": "/run/user/1000"
      }
    }
  }
}
```

Многие клиенты запускают серверы с пустым окружением. Если сервер пишет *No display*, передай
переменные дисплея в `env`, как в примере выше (на X11 это `DISPLAY=:0`). Свои значения можно узнать
командой `echo $DISPLAY $WAYLAND_DISPLAY $XDG_RUNTIME_DIR`.

### Сервер без экрана (openclaw, zeroclaw, VPS)

Запуск с виртуальным дисплеем:

```bash
xvfb-run -a uv run --directory /path/to/olx-mcp olx-mcp
```

## Инструменты

| Инструмент | Что делает |
|---|---|
| `olx_find_location(text)` | Находит `city_id` / `region_id` / `district_id` по названию (`"Łódź"`, `"Kraków"`). |
| `olx_suggest_categories(query, limit=15)` | Показывает, в каких категориях есть объявления по запросу и сколько их. По `category_id` можно сузить поиск, например отделить телефоны от чехлов. |
| `olx_category_filters(category_id)` | Фильтры категории и их допустимые значения: состояние, бренд, модель, размер… |
| `olx_resolve_url(url)` | Превращает ссылку olx.pl в параметры поиска. |
| `olx_search(...)` | Поиск объявлений (параметры ниже). |
| `olx_get_offer(offer)` | Полные данные объявления. `offer` — ссылка или id из `olx_search` в этой же сессии. |
| `olx_offer_photos(offer, max_photos=4, size=640, start=0)` | Фото объявления картинками. `max_photos` 1–8, `size` 300–1500 px, `start` для листания. |

### Параметры `olx_search`

| Параметр | Тип | Примечание |
|---|---|---|
| `query` | строка | Текст запроса. |
| `category_id` | int | Из `olx_suggest_categories` или `olx_resolve_url`. |
| `city_id`, `region_id`, `district_id` | int | Из `olx_find_location`. |
| `distance_km` | int | Радиус вокруг `city_id`. |
| `price_min`, `price_max` | число | В злотых. |
| `sort` | `relevance` \| `newest` \| `price_asc` \| `price_desc` | По умолчанию `relevance`. |
| `offset`, `limit` | int | `limit` не больше 50. Следующие страницы через `offset`. |
| `extra_filters` | объект | Фильтры из `olx_category_filters`, например `{"filter_enum_state": ["used"]}` или `{"owner_type": "private"}`. Списки превращаются в `key[0]`, `key[1]`… |

Результат: `{total, offset, returned, offers: [...]}`. У каждого объявления есть `id`, `title`, `price`,
`location`, `created`, `refreshed`, `business`, `delivery`, `condition`, `url`, `description_snippet`
и `info`.

### Проверка описания (`info`)

```json
{
  "description_chars": 42,
  "photo_count": 6,
  "needs_photo_review": true,
  "reasons": ["very short description (42 chars)"],
  "notes": ["few item parameters filled in"]
}
```

Возможные `reasons`:
- `no description` — описания нет;
- `very short description (N chars)` — короче 80 символов;
- `description mostly repeats the title` — описание в основном повторяет заголовок;
- `description is generic boilerplate` — шаблонный текст;
- `description points to the photos` — «смотрите фото».

`needs_photo_review` равен `true`, если есть хотя бы одна причина и у объявления есть фото. Тогда
инструкции сервера говорят модели открыть фото и описать, что на них видно: сам товар, видимое
состояние, повреждения, комплектность, расхождения с заголовком.

## Как это работает

- **OLX блокирует обычные HTTP-клиенты** (по отпечатку TLS) **и браузеры в фоновом (headless) режиме.**
  Поэтому сервер через Playwright управляет настоящим видимым окном Chromium и вызывает JSON-эндпоинты
  OLX изнутри страницы, как это делает сам сайт. Окно открывается при первом запросе и остаётся
  открытым. Его можно свернуть, но не закрывай, пока сервер работает (иначе оно откроется заново).
- **Данные объявления** берутся из страницы объявления (`window.__PRERENDERED_STATE__`), потому что
  JSON-эндпоинт объявления анонимным посетителям недоступен.
- **Фото** скачиваются напрямую с CDN OLX обычным HTTP, там блокировки нет.
- **Без входа в аккаунт.** У браузера свой профиль (только cookies и согласие на них), отдельный от
  твоего обычного браузера.

## Настройка

| Переменная | По умолчанию | Значение |
|---|---|---|
| `OLX_MCP_CHROMIUM` | системный `chromium` / `chrome`, иначе браузер Playwright | Путь к браузеру. |
| `OLX_MCP_PROFILE` | `~/.local/share/olx-mcp/profile` | Папка профиля браузера. |

## Ограничения

- Неофициальный внутренний API: OLX может изменить или закрыть его без предупреждения.
- Нужен дисплей или Xvfb. Полностью фоново сервер работать не может.
- `olx_get_offer` и `olx_offer_photos` по числовому id работают только для объявлений из поиска в той
  же сессии сервера. В остальных случаях передавай ссылку.
- Запросы идут по одному, с паузой не меньше 1 с, поэтому большие выборки собираются долго.
- Поддерживается только olx.pl (не olx.ua, olx.pt и т. д.).
- Только поиск: публиковать объявления и управлять ими нельзя.

```bash

```

Структура:

```
src/olx_mcp/
  server.py   MCP-инструменты и инструкции сервера
  api.py      эндпоинты OLX, форматирование, проверка описаний
  browser.py  общая сессия Chromium
  photos.py   скачивание фото с CDN
tests/        офлайн-тесты
```
